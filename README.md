# Exception_Handling
This repository contains **C++** code related to **Exception Handling** including try, throw, and catch.

## Purpose
This repository is created for learning, understanding and practising the core concepts of Exception Handling.

## Concepts Covered
- Basic exception handling
- Multiple catch blocks
- Exception in array index
- Bank management system

## How to Run

### Compile<br>
    - g++ array_index.cpp -o array_index

### Run<br>
    - .\array_index
